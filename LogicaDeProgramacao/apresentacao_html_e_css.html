Módulo 1 — Introdução

O que é a World Wide Web?

Entendendo os termos básicos do cotidiano digital.

1

Página Web

Um documento único escrito em HTML que você lê no navegador (ex: um artigo específico ou o perfil de um usuário).

2

Website (Site)

Conjunto de páginas web interconectadas sob o mesmo nome de domínio (ex: wikipedia.org).

3

Navegador (Browser)

O aplicativo (Chrome, Firefox, Edge, Safari) responsável por traduzir códigos HTML/CSS em elementos visuais interativos.

Como funciona na prática? Quando você digita um endereço, seu navegador faz um pedido a um computador remoto (Servidor), que responde enviando arquivos de código .html e .css.

Módulo 2 — Conhecendo o HTML

O que são Tags, Elementos e Atributos?

Desmontando a anatomia da linguagem de marcação.

Anatomia de uma Linha de Código HTML:

<a href="https://google.com">Visitar Google</a>
Tag de Abertura & Fechamento

<a> indica o início e </a> (com barra) indica o fim do elemento.

Atributo & Valor

href="..." fornece uma informação extra (o destino do link).

Conteúdo do Elemento

O texto visível na tela que o usuário pode clicar ("Visitar Google").

Módulo 3 — Estrutura Inicial

Estrutura Básica de um Arquivo HTML

Todo arquivo .html começa com este modelo obrigatório.

index.html UTF-8 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Meu Primeiro Site</title>
</head>
<body>

  <h1>Olá, Mundo!</h1>
  <p>Esta é minha primeira página web.</p>

</body>
</html>
<!DOCTYPE html> Avisa ao navegador que estamos utilizando a versão mais atual (HTML5).
<head> (Cabeça) Guarda configurações invisíveis ao usuário: título na aba, acentuação e links CSS.
<body> (Corpo) Contém **todo o conteúdo visível** na tela: textos, botões, imagens e vídeos.
meta charset="UTF-8" Garante a exibição correta de acentos e caracteres em português (Ex: á, ç, ã).
Módulo 4 — Elementos de Texto

Títulos, Parágrafos e Formatação

Organizando hierarquia e conteúdo escrito na sua página.

Hierarquia de Títulos (<h1> até <h6>)

Heading 1 (<h1>) — Mais importante

Heading 2 (<h2>) — Seção principal

Heading 3 (<h3>) — Subseção

Heading 4 (<h4>)

Heading 5 (<h5>)
Heading 6 (<h6>)

⚠️ Regra de Ouro: Use apenas UM <h1> por página para indicar o assunto principal!

Parágrafos e Destaques Inline

<p>Este é um parágrafo normal.</p>

<p>Texto com <strong>negrito importante</strong> e <em>itálico enfático</em>.</p>

<p>Primeira linha.<br>Segunda linha.</p>

Diferença Visual Renderizada: Texto com negrito importante e itálico enfático.
Módulo 4 — Mídia e Conexões

Listas, Links e Imagens

Tornando seu site interativo, dinâmico e rico em conteúdo visual.

Listas

<ul> e <ol>

Item de lista é sempre envolvido por <li>.

Não Ordenada (<ul>):

  • HTML
  • CSS

Ordenada (<ol>):

  1. Passo 1
  2. Passo 2
Hiperlinks

<a href="...">

Permite navegar entre páginas e sites externos.

<a href="https://site.com" target="_blank">
  Visitar Web
</a>

O atributo target="_blank" abre o link em uma nova aba do navegador.

Imagens

<img src="..." alt="...">

Tag auto-fechável (não precisa de </img>).

<img src="foto.jpg"
  alt="Foto de perfil">

⚠️ alt: essencial para leitores de tela e acessibilidade!

Módulo 5 — Estilização Visual

O que é CSS?

Cascading Style Sheets (Folhas de Estilo em Cascata).

Separação de Responsabilidades

O HTML cuida estritamente de **O QUE** está na página (conteúdo), enquanto o CSS determina **COMO** esse conteúdo é apresentado graficamente.

O que significa "Em Cascata"?

As regras são aplicadas de cima para baixo. Se houver regras conflitantes, as definidas mais abaixo (ou mais específicas) prevalecem!

# O que você pode controlar com CSS?
  • Cores de texto e fundos
  • Fontes, tamanhos e pesos
  • Espaçamentos e margens
  • Posicionamento e layouts em grade
  • Sombras, bordas arredondadas e efeitos
Módulo 5 — Sintaxe CSS

Anatomia de uma Regra CSS

Como escrever instruções corretas para o navegador estilar um elemento.

Exemplo de Código CSS:

h1 {
color: #F97316;
font-size: 24px;
}
Seletor

Indica **qual** elemento do HTML será estilizado (no caso, todos os <h1>).

Propriedade

O aspecto visual que você deseja alterar (ex: color, font-size).

Valor + Ponto e Vírgula

A nova configuração aplicada. Cada declaração **deve terminar com ponto e vírgula (;)**!

Módulo 6 — Seletores

Seletores: Elemento, Classe e ID

Como mirar exatamente no elemento que você deseja estilizar.

Seletor de Elemento

Por Tag HTML

Afeta **TODAS** as tags desse tipo na página inteira.

p {
  color: gray;
}
Ex: Aplica estilo em todos os <p>
Seletor de Classe (Mais Usado!)

Usa Ponto ( . )

Estiliza qualquer elemento que possua o atributo class="...". Reutilizável!

.cartao {
  background: white;
}
Ex: <div class="cartao">
Seletor de ID

Usa Cerquilha ( # )

Para elementos **ÚNICOS** na página (id="...").

#topo-principal {
  height: 80px;
}
Ex: <header id="topo-principal">
Módulo 6 — Propriedades Visuais

Cores, Fontes e Alinhamento

As principais propriedades para dar vida ao seu texto.

color Cor do texto (ex: #F97316 ou orange)
background-color Cor do fundo do elemento
font-family Família tipográfica (ex: Arial, Inter, sans-serif)
font-size Tamanho da fonte em pixels (ex: 16px)
text-align Alinhamento: left, center, right
// Código CSS Combinado: 
.titulo-destaque {
  color: #F97316;
  background-color: #FFEDD5;
  font-size: 20px;
  text-align: center;
  padding: 10px;
}

Módulo 6 — O Coração do CSS

O Modelo de Caixa (CSS Box Model)

No CSS, **absolutamente tudo** é uma caixa retangular!

MARGIN (Espaço Externo)
BORDER (Borda da Caixa)
PADDING (Preenchimento Interno)
CONTEÚDO (Texto, Imagem, etc.)
Margin: Afasta elementos vizinhos.
Border: A linha de contorno.
Padding: Empurra o conteúdo para dentro.
Conteúdo: O tamanho real (width/height).
Módulo 7 — Conectando HTML e CSS

Como Conectar HTML ao CSS?

As três formas de aplicar estilos — e qual é a melhor prática profissional.

Não Recomendado

1. CSS Inline

Diretamente na tag HTML com o atributo style="...".

<h1 style="color: red;">
  Título
</h1>
Uso Ocasional

2. CSS Interno

Dentro da tag <style> no cabeçalho <head>.

<head>
  <style>
    h1 { color: red; }
  </style>
</head>
Boas Práticas (Padrão)

3. CSS Externo

Arquivo style.css separado e conectado no HTML!

<head>
  <link rel="stylesheet"
        href="style.css">
</head>
Módulo 7 — Organização do Projeto

Estrutura de Arquivos Profissional

Como organizar suas pastas para manter o projeto limpo e sem links quebrados.

meu-primeiro-site/
index.html (Página Principal)
style.css (Folha de Estilos)
imagens/
perfil.jpg (Sua Foto)
1. Sempre nomeie como `index.html` Os servidores web buscam automaticamente o arquivo chamado index.html ao abrir seu site.
2. Evite espaços e acentos Use nomes simples com hífen em vez de espaços (Exemplo: minha-foto.jpg).
Módulo 8 — Estrutura Semântica

Layout e HTML Semântico

Usando as tags corretas para estruturar as áreas de uma página moderna.

<header> (Cabeçalho do Site)
<nav> Menu de Navegação
<main> Conteúdo Principal
<section> Seção "Sobre Mim"
<footer> (Rodapé - Direitos Autorais e Redes)
<header> Topo da página contendo logotipo, título do site ou menu de opções.
<main> O assunto principal e exclusivo daquela página específica.
<footer> Rodapé com contatos, copyright e links secundários.

Módulo 9 — Design Responsivo

Adaptando para Celulares e Monitores

Seu site precisa parecer incrível em qualquer tamanho de tela.

Boas Práticas de Responsividade

  • Sempre inclua a tag de viewport no <head>.
  • Use max-width: 100% em imagens para não estourar a largura da tela.
  • Prefira unidades flexíveis (%) em vez de larguras fixas exageradas em pixels.
Introdução às Media Queries: @media (max-width: 600px) { ... } Permite aplicar regras de CSS específicas para telas menores!

Módulo 9 — Qualidade do Código

Acessibilidade e Boas Práticas

Construindo a Web para **todas** as pessoas com código limpo.

Texto Alternativo (alt)

Descreva a imagem para deficientes visuais e leitores de tela.

Contraste de Cores

Garanta contraste alto entre o fundo e a cor do texto para facilidade de leitura.

Indentação Limpa

Recue o código com espaços/tabs para identificar claramente o que está dentro do quê.

Sintaxe Correta

Sempre feche suas tags e verifique caminhos de arquivos para evitar links quebrados.
