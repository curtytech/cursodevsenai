6. Formulário — <form>

A tag form é utilizada para criar formulários que recebem informações do usuário. 



















```




```
<label>Nome:</label>

<input
    type="text"
    placeholder="Digite seu nome">

<br>

<input
    type="email"
    placeholder="Digite seu e-mail">

<br>

<button type="submit">
    Cadastrar
</button>
```
```

7. Conteúdo complementar — <aside>

A tag aside é utilizada para informações complementares ao conteúdo principal.

Exemplo: uma barra lateral, links relacionados ou informações adicionais.

8. Container — <div>

Exemplo de uma div

A div é um container genérico utilizado para organizar elementos da página. 

```




```
<h3>Título</h3>

<p>
    Conteúdo dentro da div.
</p>
```
```

9. Desafio

Crie uma página de cadastro de aluno utilizando as tags aprendidas nesta aula.

Sua página deverá possuir:

  • Um título com h1
  • Parágrafos com p
  • Texto destacado com span
  • Texto em negrito com b
  • Texto em itálico com i
  • Quebras de linha com br
  • Separações com hr
  • Um formulário com form
  • Campos utilizando input
  • Um botão utilizando button
  • Uma imagem utilizando img
  • Um link utilizando a
