O que é Modelagem de Negócios?

Módulo 2

📌 Definição

Modelagem de negócios é a representação estruturada de como uma organização cria, entrega e captura valor — descrevendo seus processos, atividades, recursos e relacionamentos.

🔄 Componentes básicos

→
Entrada
O que chega ao processo
⚙️
Atividade
O que é feito
←
Saída
O resultado gerado
🔗
Relação
Como os setores se conectam

Exemplo: Loja de Roupas

🧵 Fornecedor envia roupas
↓
📦 Estoque é cadastrado no sistema
↓
🛒 Cliente realiza compra
↓
📊 Venda registrada — relatório gerado

💡 Por que modelar? Para entender como o negócio funciona antes de criar ou melhorar sistemas.

Organização de Dados

Módulo 3

Por que organizar dados?

Dados desorganizados geram decisões erradas, retrabalho e prejuízos. Organizar é a base de qualquer sistema eficiente.

Classificação

Separar dados por tipo, categoria ou origem.

📐

Estruturação

🔍

Identificação

Encontrar os dados relevantes para cada análise.

🧹

Limpeza

Remover duplicatas, corrigir erros e padronizar formatos.

Roteiro de Trabalho — Checklist

Módulo 3.1

O que é um Checklist?

Uma lista sequencial de tarefas ou verificações que garante que nada seja esquecido durante um processo de trabalho.

Exemplo: Levantamento de informações de um cliente

1.
Identificar o setor ou processo a ser analisado
2.
Listar as informações necessárias (campos, dados)
3.
Definir as fontes de coleta (formulário, planilha, entrevista)
4.
Coletar os dados conforme o roteiro
5.
Verificar a qualidade e completude dos dados
6.
Organizar os dados em tabelas ou planilhas
7.
Validar as informações com o responsável
📋

Por que usar?

  • ✔ Evita esquecimentos
  • ✔ Padroniza o processo
  • ✔ Facilita o trabalho em equipe
  • ✔ Reduz erros e retrabalho
  • ✔ Permite rastrear o progresso
💡 Analogia: Como o pré-voo de um piloto de avião — cada item precisa ser verificado antes de decolar!

Métodos e Técnicas de Trabalho

Módulo 3.3
🗓️

Planejamento

Definir metas, prazos e responsáveis antes de executar qualquer tarefa.

Ex: Criar um cronograma de levantamento de requisitos
🎯

Priorização

Separar o urgente do importante. Trabalhar primeiro no que gera mais impacto.

Ex: Matriz Urgente × Importante (Eisenhower)
📏

Padronização

Criar procedimentos padrão para que qualquer pessoa da equipe possa executar a mesma tarefa.

Ex: Procedimento Operacional Padrão (POP)
📊

Organização das atividades

Dividir o trabalho em etapas menores, acompanhar o progresso e ajustar quando necessário.

Ex: Kanban — A fazer | Em andamento | Concluído

Ciclo PDCA — Melhoria Contínua

Módulo 3.5
📋
P — Plan
Planejar
  • • Identificar o problema
  • • Definir metas
  • • Escolher ações
🚀
D — Do
Executar
  • • Implementar o plano
  • • Treinar a equipe
  • • Registrar resultados
🔍
C — Check
Verificar
  • • Comparar com a meta
  • • Analisar desvios
  • • Usar dados coletados
🛠️
A — Act
Agir / Corrigir
  • • Corrigir os desvios
  • • Padronizar o sucesso
  • • Reiniciar o ciclo 🔄
💡 O PDCA é cíclico — após o A, retorna ao P com melhorias incorporadas. A empresa evolui a cada ciclo!
📌

PDCA na prática — Estudo de caso

Módulo 3.5

🚨 Problema: Clientes reclamando de demora no atendimento

Tempo médio de resposta: 48 horas. Meta: 4 horas.

P

Planejar

Mapear o processo de atendimento; identificar gargalos; treinar 2 novos atendentes; implantar sistema de tickets.

D

Executar

Treinar equipe, configurar sistema de tickets, criar SLA (prazo máximo de resposta), comunicar ao cliente.

C

Verificar

Após 30 dias: tempo médio caiu para 6 horas. Satisfação do cliente subiu de 62% para 84%.

A

Agir

Meta não atingida (6h vs 4h). Novo ciclo: automação de triagem de tickets e chatbot para respostas simples.

📈

Resultado do 1º ciclo

Tempo resposta -87,5%
Satisfação +22%
🔄 O ciclo nunca termina — sempre há algo a melhorar!

Autonomia Profissional

Módulo 4

O que é autonomia?

É a capacidade de tomar decisões, resolver problemas e executar tarefas sem depender constantemente de supervisão — mas sempre com responsabilidade.

🧠

Tomada de decisão

Avaliar opções e escolher a melhor com base nos dados disponíveis.

🔧

Busca por soluções

Pesquisar, testar e implementar soluções sem esperar que alguém resolva por você.

📋

Trabalho independente

Organizar a própria agenda, prioridades e entregas com disciplina.

🤝

Responsabilidade

Responder pelos resultados das próprias decisões — bons ou ruins.

Espectro da autonomia

😰
Dependência total
Precisa de aprovação para tudo
🤔
Iniciativa básica
Age em tarefas rotineiras
💪
Autonomia saudável
Decide + comunica + responde
🌟
Liderança
Guia outros com autonomia
🎯 O objetivo é a Autonomia Saudável: liberdade + responsabilidade.
⚖️

Consequências Favoráveis e Desfavoráveis

Módulo 4.1

✅ Autonomia com responsabilidade

+
Maior produtividade
Menos tempo esperando aprovações, mais tarefas concluídas.
+
Resolução rápida de problemas
Equipe age imediatamente, sem esperar o gestor para cada detalhe.
+
Melhoria nos resultados
Profissionais autônomos inovam e encontram soluções criativas.
+
Crescimento profissional
Quem age com autonomia responsável é percebido como líder.
VS

❌ Autonomia sem responsabilidade

−
Decisões incorretas
Agir sem informação ou sem alinhamento gera erros custosos.
−
Falhas de comunicação
Equipe age sem informar o grupo — trabalho duplicado ou contraditório.
−
Impactos negativos no projeto
Um passo errado pode comprometer o cronograma e o orçamento.
−
Perda de confiança
Decisões ruins sem transparência destroem a credibilidade.

Prática

🏪 Situação: Empresa "TechVendas Ltda."

Uma loja de eletrônicos percebeu que suas vendas online caíram 30% em 3 meses consecutivos. O gestor pediu à equipe de TI para analisar os dados e propor soluções. Os dados disponíveis são: relatórios de vendas, cadastro de clientes, histórico de reclamações e tempo médio de entrega.

Responda em equipe:

1.
Como você organizaria os dados disponíveis para iniciar a análise? Quais campos seriam mais relevantes?
2.
Monte um checklist com as 5 primeiras etapas do seu roteiro de trabalho.
3.
Como aplicaria o Ciclo PDCA para resolver o problema de queda nas vendas? Descreva cada etapa.
4.
Que decisão você tomaria de forma autônoma e qual decisão dependeria da aprovação do gestor? Justifique.
5.
Desenhe um Canvas simplificado (3 blocos) para a TechVendas: Proposta de Valor, Clientes e Canais.
