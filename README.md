# CursoDevSENAI

Site desenvolvido para **auxiliar os alunos do curso de Desenvolvimento de Sistemas do SENAI**, reunindo conteúdos didáticos, materiais de apoio, exemplos e atividades.

## Conteúdos

Atualmente, o projeto conta com conteúdos relacionados a:

* **Lógica de Programação**
* **HTML**
* **CSS**
* Materiais e atividades de apoio

Novos conteúdos serão adicionados conforme o andamento do curso.

## Objetivo

Facilitar o acesso aos materiais utilizados durante as aulas e disponibilizar um espaço organizado para estudo e revisão dos conteúdos.

## Tecnologias

* HTML5
* CSS3
* JavaScript
