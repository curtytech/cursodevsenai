## 📖 Sobre o projeto

O **CursoDevSENAI** é um site desenvolvido para **auxiliar os alunos do curso de Desenvolvimento de Sistemas do SENAI**, reunindo conteúdos didáticos, materiais de apoio, exemplos e atividades.

A proposta é facilitar o acesso aos materiais utilizados durante as aulas e disponibilizar um espaço organizado para estudo e revisão dos conteúdos.

---

## 📚 Conteúdos

Atualmente, o projeto conta com conteúdos relacionados a:

|           Conteúdo           | Descrição                                                                         |
| :--------------------------: | --------------------------------------------------------------------------------- |
| 🧠 **Lógica de Programação** | Conceitos fundamentais para o desenvolvimento do raciocínio lógico e programação. |
|          🌐 **HTML**         | Conteúdos introdutórios sobre estrutura e criação de páginas web.                 |
|          🎨 **CSS**          | Conceitos básicos de estilização e apresentação de páginas.                       |
|   📑 **Materiais de Apoio**  | Arquivos, exemplos, atividades e outros materiais utilizados durante o curso.     |

> 💡 Novos conteúdos serão adicionados conforme o andamento do curso.

---

## 🎯 Objetivo

O projeto tem como objetivo:

* 📌 Facilitar o acesso aos materiais utilizados durante as aulas;
* 📚 Reunir conteúdos didáticos em um único lugar;
* 💻 Disponibilizar exemplos e atividades;
* 🔎 Facilitar a revisão dos conteúdos;
* 🤝 Servir como ferramenta de apoio para os alunos da turma.
