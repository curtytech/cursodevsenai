Padrão Brasileiro (Norma ABNT2 no Windows)

O teclado ABNT2 possui a tecla Ç, tecla AltGr para terceiro nível e teclas mortas de acentuação (como ~, ^ e `). Devido a essas particularidades físicas, atalhos de editores internacionais exigem adaptações: no VS Code em ABNT2, use Ctrl+; para comentar linhas e Ctrl+' para o terminal!

Comentar Linha: Ctrl + ; Terminal: Ctrl + ' Dividir Editor: Ctrl + \ Comentário em Bloco: Shift + Alt + A

code Manipulação & Edição de Linhas
comment
Comentar Linha (Norma ABNT2)
Transforma a linha onde está o cursor em comentário (ou remove as barras de comentário).
⚠️ Padrão ABNT2: No Windows brasileiro a tecla de fábrica é o ponto e vírgula ( ; )! A barra no teclado numérico também funciona.
Ctrl + ; ou Ctrl + / [NumPad]
notes
Comentar em Bloco (Multi-linhas)
Envolve a seleção em comentário de bloco, como /* ... */ em CSS/JS ou <!-- ... --> em HTML.
💡 No dia a dia: Desative funções inteiras temporariamente sem poluir cada linha.
Shift + Alt + A
content_copy
Duplicar Linha de Código
Clona a linha atual inteira para baixo ou para cima instantaneamente sem precisar selecionar!
⚡ Agilidade Extrema: Nunca mais copie e cole para duplicar tags ou regras.
Shift + Alt + ↓ ou ↑
swap_vert
Mover Linha para Cima / Baixo
Desloca a linha ou bloco selecionado para cima ou para baixo com total fluidez.
💡 No dia a dia: Reorganize a ordem de regras CSS ou variáveis em 1 segundo.
Alt + ↑ ou ↓
delete
Apagar Linha Inteira
Deleta a linha inteira onde está o cursor sem precisar selecionar com o mouse.
💡 Produtividade: Elimina a linha sem deixar espaços vazios indesejados.
Ctrl + Shift + K
auto_fix_high
Formatar Documento (Indentação)
Alinha chaves, quebras de linha e espaços do arquivo de forma limpa e profissional.

Shift + Alt + F
wrap_text
Quebra Automática de Linha (Word Wrap)
Faz linhas longas de texto se ajustarem à largura da tela sem exigir rolagem horizontal.

Alt + Z
keyboard_return
Inserir Linha Abaixo / Acima (Sem Quebrar)
Cria uma nova linha limpa imediatamente abaixo (ou acima) de onde você está, mesmo se o cursor estiver no meio da frase!
⚡ Agilidade: Dispensa ter que usar as setas até o fim da linha antes de dar Enter.
Ctrl + Enter (acima: Ctrl + Shift + Enter)
ads_click Múltiplos Cursores & Produtividade no VSCode
filter_none
Selecionar Próxima Ocorrência (Multi-Cursor com Ctrl+D)
Selecione uma palavra ou tag (ou posicione o cursor sobre ela) e aperte Ctrl+D repetidamente para encontrar a próxima ocorrência idêntica e criar um novo cursor nela. Tudo o que digitar será modificado em todos os locais simultaneamente!
⚡ Controle Total: Apertou uma vez a mais? Use Ctrl+U para desfazer o último cursor! Para pular sem selecionar, tecle Ctrl+K seguido de Ctrl+D.
Ctrl + D (Pular: Ctrl + K, Ctrl + D)
undo
Desfazer Último Cursor Adicionado
Remove o último cursor selecionado pelo Ctrl+D mantendo os anteriores ativos e sem desfazer o texto que você já digitou.
⭐ Indispensável: Apertou Ctrl+D rápido demais e pegou uma palavra que não devia? Use Ctrl+U para recuar!
Ctrl + U
format_align_right
Adicionar Cursores no Fim de Cada Linha
Selecione um bloco com várias linhas e aperte este atalho para posicionar um cursor piscando no final de cada uma delas simultaneamente!
⚡ Super Poder: Coloque vírgulas em 20 propriedades de um objeto ou feche 15 tags ao mesmo tempo em 1 segundo.
Shift + Alt + I
dynamic_feed

Cria cursores em todas as palavras idênticas do arquivo inteiro de uma só vez.

Ctrl + Shift + L
mouse
Múltiplos Cursores Livres
Segure o Alt e clique onde quiser para digitar em vários pontos. Ou use Ctrl+Alt+Setas para empilhar.
💡 Exemplo: Adicione aspas e vírgulas em 10 itens de um array simultaneamente.
Alt + Clique ou Ctrl + Alt + ↑ / ↓
select
Seleção em Bloco / Coluna Retangular
Permite selecionar um retângulo vertical de texto segurando as teclas e arrastando com o botão do mouse ou usando as setas.
💡 No dia a dia: Ideal para apagar números de linhas colados ou adicionar prefixos em várias linhas alinhadas.
Shift + Alt + Arrastar Mouse
zoom_out_map
Expandir / Reduzir Seleção Inteligente
Expande a seleção respeitando a estrutura do código: palavra → conteúdo entre aspas → tag HTML inteira → bloco pai!
💡 No dia a dia: Selecione blocos de HTML ou funções inteiras sem risco de esquecer chaves de fechamento.
Shift + Alt + → / ←
lightbulb
Forçar Autocompletar (IntelliSense)
Abre a lista suspensa com sugestões de propriedades CSS, tags HTML, variáveis e métodos.
💡 No dia a dia: Esqueceu a sintaxe exata de uma propriedade? Use este atalho!
Ctrl + Espaço
drive_file_rename_outline

F2

O cérebro do VS Code. Executa qualquer recurso, altera configurações e roda extensões.

Ctrl + Shift + P ou F1
search
Localizar e Abrir Arquivo Rápido

Ctrl + P

Abrir / Fechar Terminal (Norma ABNT2)
Exibe ou oculta o terminal integrado na parte inferior para rodar comandos Git, Node ou Python.

Ctrl + ' ou Ctrl + J
view_sidebar
Mostrar / Ocultar Barra Lateral (Explorer)
Oculta a árvore de arquivos para liberar mais espaço de tela para escrever código.

Ctrl + B
vertical_split
Dividir Editor em Colunas (Split)
Abre o código em duas colunas paralelas para visualizar o HTML e o CSS lado a lado.

Ctrl + \
pin

O terminal acusou erro na linha 145? Digite o número da linha e pule até ela instantaneamente.
💡 No dia a dia: Pressione o atalho, digite o número da linha e dê Enter.
Ctrl + G
find_replace
Localizar e Substituir no Arquivo
Abre o painel de substituição para trocar palavras ou códigos no documento atual com 1 clique.

Ctrl + S (Todos: Ctrl + K, S)

Menu Arquivo ➔ Auto Save

code 4. Emmet Abbreviation no VS Code (HTML & CSS)

16 Atalhos
account_tree Estrutura & Hierarquia HTML
rocket_launch
Esqueleto HTML5 Completo
Gera a estrutura completa de um documento HTML5 com doctype, meta tags, viewport e body.
⚡ Como usar: Em um arquivo .html vazio, digite ! e tecle Tab ou Enter.
! ou html:5 + Tab
subdirectory_arrow_right
Elementos Filhos (Operador >)
Cria elementos aninhados dentro de outros (nível descendente na hierarquia).
⚡ Exemplo: nav>ul>li>a vira um menu completo com link dentro da lista.
nav>ul>li>a + Tab
drag_indicator
Elementos Irmãos (Operador +)
Cria elementos no mesmo nível de hierarquia (um imediatamente após o outro).
⚡ Exemplo: header+main+footer gera os três blocos semânticos paralelos.
header+main+footer + Tab
north
Subir Nível na Árvore (Operador ^)
Sai do elemento filho atual e volta um degrau para cima na hierarquia da árvore HTML.
⚡ Exemplo: div>p^span cria o <p> dentro da div e o <span> irmão da div.
div>p^span + Tab
close
Multiplicação de Elementos (Operador *)
Repete a criação do elemento pelo número de vezes especificado.
⚡ Exemplo: ul>li*5>a gera uma lista <ul> com 5 itens <li> contendo links.
ul>li*5>a + Tab
palette Classes, IDs, Atributos & Textos HTML
sell
Classes e IDs Automáticos (. e #)
Define classes com ponto (.) e IDs com cerquilha (#). Sem tag antes, cria uma <div>!
⚡ Exemplo: .card vira <div class="card"></div>. Ou h1#titulo.principal.
.container#app + Tab
pin
Numeração Sequencial (Operador $)
Insere numeração crescente de 1 em diante em classes, IDs ou textos multiplicados.
⚡ Exemplo: li.item-$*3 cria item-1, item-2 e item-3. Com $$ cria 01, 02.
li.item-$*3 + Tab
title

Adiciona o texto literal diretamente dentro do elemento gerado usando chaves.
⚡ Exemplo: button.btn{Clique Aqui} vira <button class="btn">Clique Aqui</button>.
button.btn{Salvar} + Tab
settings_input_component
Atributos Personalizados ([])
Permite adicionar qualquer atributo HTML (como type, placeholder, src) entre colchetes.
⚡ Exemplo: input[type="email" placeholder="Seu e-mail" required] gera o input pronto!
input[type="email" required] + Tab
category
Agrupamento com Parênteses ( () )
Agrupa blocos inteiros para manter a ordem matemática na árvore de elementos.
⚡ Exemplo: (header>nav)+(main>article)+footer constrói a página inteira em 1 linha!
(header>nav)+main+footer + Tab
article
Gerador de Texto Dummy (Lorem Ipsum)
Cria parágrafos ou frases em latim para testar o layout sem precisar pensar no texto.

Largura & Altura Dinâmicas (w / h)
Escreva dimensões em pixels, porcentagens (p) ou unidades de tela (vh / vw).

format_shapes

Abreviações universais para propriedades visuais de rotina.
⚡ No CSS: tac (text-align: center) | poa (position: absolute) | por (position: relative) | bsh (box-shadow).
tac / poa / bsh + Tab
