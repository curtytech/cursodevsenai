Conheça o Flask

Flask é um framework web leve e flexível desenvolvido em Python. Ele permite criar sites, APIs e aplicações web de maneira simples, organizada e rápida.

Introdução

O que é Flask?

Entenda o conceito básico desse framework.

Flask é um microframework para desenvolvimento web utilizando a linguagem Python.

Ele fornece ferramentas essenciais para criar aplicações web, permitindo que o desenvolvedor escolha outras bibliotecas e recursos conforme a necessidade do projeto.

Por ser simples e flexível, Flask é bastante utilizado para projetos pequenos, APIs, sistemas web e protótipos.

Características

  • Desenvolvido em Python
  • Leve e flexível
  • Fácil de aprender
  • Suporte para criação de APIs
  • Permite utilizar extensões
  • Possui sistema de rotas
  • Suporta templates HTML
Biblioteca

A biblioteca Flask

Entenda como Flask é importado e utilizado em Python.

Para utilizar o Flask em um programa Python, é necessário importar a classe Flask. Essa classe permite criar uma aplicação web, definir rotas e iniciar o servidor.

Biblioteca Flask 
from flask import Flask

app = Flask(__name__)

@app.route("/")
def inicio():
    return "Olá, mundo!"

if __name__ == "__main__":
    app.run(debug=True)

1. Importando Flask

from flask import Flask

Essa linha importa a classe Flask da biblioteca. É através dela que a aplicação será criada.

2. Criando a aplicação

app = Flask(__name__)

Cria uma instância da aplicação Flask. A variável app representa o aplicativo web.

3. Criando uma rota

@app.route("/")

Define a URL que será utilizada. Nesse exemplo, a rota / representa a página inicial.

4. Criando uma função

def inicio():

A função será executada quando a rota correspondente for acessada pelo usuário.

5. Enviando uma resposta

return "Olá, mundo!"

O comando return envia uma resposta para o navegador.

6. Iniciando o servidor

app.run(debug=True)

Inicia o servidor de desenvolvimento do Flask. O modo debug ajuda durante o desenvolvimento.

⚠️ Importante

O Flask é uma biblioteca/framework do Python. Portanto, o código acima é executado em um arquivo .py, e não diretamente pelo navegador. O HTML desta página serve para explicar e apresentar o funcionamento do Flask.

Funcionamento

Como o Flask funciona?

Uma aplicação Flask recebe requisições e retorna respostas para o navegador ou para outro cliente.

01

Requisição

O navegador ou outro cliente envia uma requisição para uma rota da aplicação.

02

Rota

O Flask identifica a rota correspondente e executa a função definida pelo desenvolvedor.

03

Resposta

A aplicação retorna uma resposta, que pode ser uma página HTML, texto ou dados de uma API.

Primeiros passos

Como instalar o Flask?

O Flask pode ser instalado através do gerenciador de pacotes do Python.

1. Verifique o Python

Primeiro, é necessário ter o Python instalado no computador. 

python --version

2. Instale o Flask

Utilize o pip para instalar o framework: 

pip install flask

3. Ambiente virtual

É recomendado utilizar um ambiente virtual para separar as dependências de cada projeto. 

python -m venv venv

4. Execute a aplicação

Depois de criar seu arquivo Python, execute sua aplicação pelo terminal. 

python app.py
Organização

Estrutura de um projeto Flask

Um projeto pode ser organizado em diferentes arquivos e pastas.

meu_projeto/
├── app.py
├── templates/
│   └── index.html
├── static/
│   ├── style.css
│   └── script.js
└── requirements.txt

O que cada parte faz?

app.py: normalmente contém a configuração principal e as rotas da aplicação.

templates: armazena páginas HTML que podem ser renderizadas pelo Flask.

static: pode armazenar arquivos CSS, JavaScript e imagens.

requirements.txt: lista as dependências Python utilizadas pelo projeto.

Exemplo

Primeiro código com Flask

Um exemplo simples de aplicação Flask.

app.py 
from flask import Flask

app = Flask(__name__)

@app.route("/")
def inicio():
    return "Olá, mundo!"

if __name__ == "__main__":
    app.run(debug=True)
Rotas

Exemplo com várias páginas

Rotas Flask 
@app.route("/")
def inicio():
    return "Página inicial"


@app.route("/sobre")
def sobre():
    return "Página sobre nós"


@app.route("/contato")
def contato():
    return "Página de contato"

Recursos

Conceitos importantes do Flask

Alguns recursos que aparecem em aplicações Flask.

Rotas

Rotas conectam URLs a funções Python.

Elas permitem definir o que deve acontecer quando o usuário acessa determinado endereço.

Templates

O Flask pode utilizar o mecanismo de templates Jinja para gerar páginas HTML dinamicamente.

Isso permite inserir informações vindas do Python dentro do HTML.

Formulários

Aplicações Flask podem receber dados enviados por formulários HTML através de requisições HTTP.

JSON e APIs

Flask pode ser utilizado para criar APIs que retornam informações em formato JSON.

Banco de dados

Flask pode trabalhar com bancos de dados através de bibliotecas e extensões.

  • SQLite
  • MySQL
  • PostgreSQL

Extensões

O Flask possui diversas extensões que adicionam funcionalidades ao projeto.

  • Autenticação
  • Banco de dados
  • Formulários
  • Login e sessões
Templates

Flask e Jinja

O Jinja permite criar páginas HTML dinâmicas.

index.html 
<h1>Olá, {{ nome }}!</h1>

<p>Bem-vindo ao meu site.</p>

Como funciona?

O Python pode enviar uma variável chamada nome para o template. O Jinja então substitui {{ nome }} pelo valor recebido.

Boas práticas

Segurança em aplicações Flask

Desenvolver uma aplicação web também exige cuidados com segurança.

🔐 Senhas

Nunca armazene senhas diretamente em texto puro. Utilize técnicas apropriadas de hash.

🛡️ Debug

O modo debug é útil durante o desenvolvimento, mas não deve ser utilizado de maneira inadequada em produção.

🔑 Segredos

Chaves secretas, senhas e credenciais não devem ficar expostas diretamente no código público.

📦 Dependências

Mantenha as dependências do projeto organizadas e atualizadas de acordo com as necessidades.
