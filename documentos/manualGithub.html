# Manual Rápido de Git e GitHub

Um guia direto para sair do zero e chegar ao seu primeiro push: criar conta, instalar o Git, versionar um projeto e publicá-lo no GitHub.

git init git add git commit git push git clone
1

O que são Git e GitHub?

Git é uma ferramenta usada para controlar versões dos seus projetos. Ele registra as alterações feitas no código e permite voltar a versões anteriores.

GitHub é uma plataforma online onde podemos armazenar, compartilhar e colaborar em projetos que utilizam Git.

resumo
Git    = controla as versões do código
GitHub = armazena o projeto online
2

Criando uma conta no GitHub

Acesse github.com e siga os passos:

  1. Clique em Sign up.
  2. Informe seu e-mail.
  3. Crie uma senha.
  4. Escolha seu nome de usuário.
  5. Confirme seu e-mail.
  6. Conclua as etapas solicitadas.
✅ Sua conta GitHub está pronta!
3

Baixando e instalando o Git

Acesse git-scm.com/downloads:

  1. Escolha Windows.
  2. Baixe o instalador.
  3. Execute o arquivo baixado.
  4. Durante a instalação, mantenha as opções padrão.
  5. Clique em Install.
  6. Ao terminar, clique em Finish.

Verificando a instalação

Abra o Git Bash ou o terminal do VS Code:

git --version
git version 2.x.x

Se algo parecido apareceu, o Git foi instalado corretamente. ✅

4

Configurando o Git

No terminal, informe seu nome e o e-mail usado no GitHub:

git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"

Pronto! O Git está configurado.

5

Criando seu primeiro projeto

Crie uma pasta para o projeto, por exemplo meu-primeiro-projeto, e dentro dela um arquivo index.html:

index.html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Meu primeiro projeto</title>
</head>
<body>
    <h1>Meu primeiro projeto com Git!</h1>
</body>
</html>
6

Criando o repositório Git local

Abra o terminal dentro da pasta do projeto e execute:

git init
# Agora o Git começou a controlar seu projeto

git status
7

Criando o repositório no GitHub

Acesse github.com:

  1. Clique em +.
  2. Clique em New repository.
  3. Digite um nome, por exemplo meu-primeiro-projeto.
  4. Escolha Public ou Private.
  5. Clique em Create repository.
Para este primeiro exercício, deixe o repositório vazio. Não marque README, .gitignore ou License.
8

Conectando o projeto ao GitHub

O GitHub fornecerá uma URL semelhante a https://github.com/seuusuario/meu-primeiro-projeto.git. No terminal do seu projeto:

git remote add origin https://github.com/seuusuario/meu-primeiro-projeto.git
git remote -v
9

Fazendo o primeiro commit

Primeiro, adicione os arquivos e depois crie o commit — o registro da versão atual do projeto:

git add .
git commit -m "Primeiro commit"
10

Enviando o projeto para o GitHub

Garanta que a branch seja main e envie o projeto:

git branch -M main
git push -u origin main
🎉 Pronto! Seu projeto agora está no GitHub.
11

Fazendo uma alteração

Abra o index.html e altere, por exemplo, o título de Meu primeiro projeto com Git! para Meu primeiro projeto com Git e GitHub!. Salve o arquivo e confira:

git status
O Git mostrará que o arquivo foi alterado
12

Registrando e enviando a alteração

git add .
git commit -m "Atualiza título da página"
git push

Pronto! A alteração agora também está no GitHub.

13

Fazendo um Git Clone

Imagine que você está em outro computador e quer baixar o projeto que está no GitHub. No repositório, clique em Code, selecione HTTPS e copie a URL.

git clone https://github.com/seuusuario/meu-primeiro-projeto.git
cd meu-primeiro-projeto
git status

O Git criará uma cópia completa do projeto no computador.

🧠 Comandos essenciais

Comando Função Tipo
git init Inicia o Git no projeto setup
git status Mostra o estado do projeto setup
git add . Prepara as alterações add
git commit -m "mensagem" Registra uma versão commit
git push Envia para o GitHub push
git pull Baixa atualizações do GitHub pull
git clone URL Clona um projeto setup
git remote -v Mostra o repositório remoto setup
