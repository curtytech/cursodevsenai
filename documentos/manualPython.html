01 — Fundamentos

Comece pelos blocos básicos

Antes de criar programas complexos, você precisa entender como Python guarda e manipula informações.

📦

Variáveis

Guardam informações que podem ser utilizadas durante a execução do programa. 

nome = "João"
idade = 25
🔤

Strings

Textos são representados normalmente entre aspas simples ou duplas. 

nome = "Maria"
🔢

Números

Python trabalha com números inteiros, decimais e operações matemáticas. 

idade = 25
preco = 19.90
✓

Booleanos

Representam apenas dois estados: verdadeiro ou falso. 

logado = True
bloqueado = False

str

list

02 — Condições e controle

Estruture decisões com clareza

ELIF

O elif significa "senão, se". Ele é usado quando precisamos verificar mais de uma condição. 

idade = 15

if idade >= 18:
    print("Adulto")
elif idade >= 13:
    print("Adolescente")
else:
    print("Criança")

Operadores de comparação

Operador Significado
== igual
!= diferente
> maior
< menor
>= maior ou igual

Diferença entre = e ==

O símbolo = atribui valor. Já == compara valores. 

idade = 20

if idade == 20:
    print("A idade é 20")

Operadores lógicos

Operador Significado
and E
or OU
not NÃO

True e False

Em Python, valores booleanos representam verdadeiro ou falso.

Listas

Uma lista armazena vários valores em uma mesma variável. 

frutas = ["maçã", "banana", "laranja"]
print(frutas[0])

if "banana" in frutas:
    print("Banana encontrada")
04 — Repetições

Repita trechos com eficiência

FOR

frutas = ["maçã", "banana", "laranja"]

for fruta in frutas:
    print(fruta)

RANGE

for numero in range(1, 6):
    print(numero)

WHILE

contador = 0

while contador < 5:
    print(contador)
    contador += 1

BREAK e CONTINUE

for numero in range(10):
    if numero == 5:
        break

    if numero == 2:
        continue

    print(numero)

06 — Estruturas de dados

Dicionários e organização de dados

Dicionários

Dicionários armazenam dados no formato chave → valor. 

pessoa = {
    "nome": "Carlos",
    "idade": 25,
    "cidade": "Rio de Janeiro"
}

print(pessoa["nome"])

Principais tipos

  • str → texto
  • int → inteiro
  • float → decimal
  • bool → verdadeiro/falso
  • list → lista
  • dict → dicionário
05 — Operadores

Operadores matemáticos e lógicos

Com eles você faz cálculos, compara valores e controla decisões no programa.

Operador Função Exemplo
+ Soma 10 + 5
- Subtração 10 - 3
* Multiplicação 4 * 5
/ Divisão 20 / 4
% Resto da divisão 10 % 3
** Potenciação 2 ** 3
// Divisão inteira 9 // 2

Operadores de atribuição

Eles servem para alterar o valor de uma variável de forma curta.

valor *= 2
