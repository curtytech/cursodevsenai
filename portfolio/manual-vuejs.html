01 / Introdução

O que é Vue.js?

Vue.js é um framework JavaScript utilizado para construir interfaces de usuário e aplicações web interativas. Ele permite atualizar partes da página automaticamente quando os dados mudam.

É conhecido por sua abordagem progressiva: você pode usá-lo em um pequeno elemento HTML ou construir uma aplicação completa com componentes, rotas e gerenciamento de estado.

⚡

Reatividade

A interface acompanha as alterações nos dados reativos.

🧩

Componentes

Divida a aplicação em partes reutilizáveis e organizadas.

🚀

Flexibilidade

Comece com uma página simples e evolua para um projeto maior.

🛠️

Ecossistema

Use ferramentas como Vue Router, Pinia e Vite.

Vue.js, HTML, CSS e JavaScript

  • HTML: define a estrutura da página.
  • CSS: controla cores, espaçamentos e aparência.
  • JavaScript: implementa a lógica da aplicação.
  • Vue.js: conecta os dados à interface e organiza a construção da aplicação.

Importante: Vue.js não substitui HTML, CSS ou JavaScript. Ele trabalha junto dessas tecnologias.

02 / Configuração

Como instalar e começar

Opção 1 — Usar Vue.js por CDN

Ideal para aprender e testar Vue em um arquivo HTML. É necessário ter conexão com a internet para carregar a biblioteca.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Meu primeiro Vue</title>
</head>
<body>
    <div id="app">
        <h1>{{ mensagem }}</h1>
    </div>

    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
    <script>
        const { createApp, ref } = Vue;

        createApp({
            setup() {
                const mensagem = ref("Olá, Vue.js!");
                return { mensagem };
            }
        }).mount("#app");
    </script>
</body>
</html>

Opção 2 — Criar um projeto com Vite

Para projetos maiores, o recomendado é utilizar uma ferramenta de desenvolvimento como Vite.

# Instale uma versão compatível do Node.js
# Abra o terminal e execute:

npm create vue@latest

# Entre na pasta criada
cd nome-do-projeto

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev

Dica: durante a criação do projeto, você poderá escolher recursos adicionais, como TypeScript, Vue Router e Pinia. Para iniciantes, comece com as opções que já entende.

Estrutura comum de um projeto

meu-projeto/
├── public/
├── src/
│   ├── assets/
│   ├── components/
│   ├── views/
│   ├── App.vue
│   └── main.js
├── index.html
├── package.json
└── vite.config.js
  • src/: código principal da aplicação.
  • components/: componentes reutilizáveis.
  • views/: páginas da aplicação, quando adotada essa organização.
  • App.vue: componente raiz.
  • main.js: ponto de entrada da aplicação.
  • package.json: dependências e scripts do projeto.
03 / Fundamentos

Reatividade e dados

Reatividade é um dos conceitos centrais do Vue. Quando um dado reativo muda, o Vue atualiza as partes da interface que dependem dele.

Usando ref()

ref() cria uma referência reativa. No JavaScript, seu valor é acessado com .value; nos templates do Vue, normalmente o valor é desembrulhado automaticamente.

<script setup>
import { ref } from 'vue';

const contador = ref(0);

function incrementar() {
    contador.value++;
}
</script>

<template>
    <p>Contador: {{ contador }}</p>
    <button @click="incrementar">Somar</button>
</template>

Usando reactive()

reactive() torna um objeto reativo. É útil quando você quer agrupar propriedades relacionadas.

<script setup>
import { reactive } from 'vue';

const aluno = reactive({
    nome: 'Lucas',
    curso: 'Desenvolvimento de Sistemas',
    ativo: true
});

function alterarNome() {
    aluno.nome = 'Marina';
}
</script>

<template>
    <p>Aluno: {{ aluno.nome }}</p>
    <p>Curso: {{ aluno.curso }}</p>
    <button @click="alterarNome">Alterar nome</button>
</template>

ref() ou reactive()?

RecursoUso comumObservação
ref()Valores e objetosO acesso no JavaScript usa .value.
reactive()Objetos reativosAs propriedades são acessadas diretamente.

Interpolação

Use a sintaxe {{ "{{ valor }}" }} para exibir dados em um template.

<script setup>
import { ref } from 'vue';
const nome = ref('Davi');
</script>

<template>
    <h1>Bem-vindo, {{ "{{ nome }}" }}!</h1>
</template>

computed()

Cria um valor derivado de outros dados reativos. O Vue atualiza o resultado quando suas dependências mudam.

<script setup>
import { ref, computed } from 'vue';

const preco = ref(100);
const quantidade = ref(3);

const total = computed(() => preco.value * quantidade.value);
</script>

<template>
    <p>Total: R$ {{ "{{ total }}" }}</p>
</template>

watch()

Permite executar uma ação quando uma fonte reativa observada muda. É útil para efeitos colaterais, como salvar preferências ou consultar uma API.

<script setup>
import { ref, watch } from 'vue';

const pesquisa = ref('');

watch(pesquisa, (novoValor, valorAnterior) => {
    console.log('Antes:', valorAnterior);
    console.log('Agora:', novoValor);
});
</script>

Regra prática: prefira computed() para calcular valores derivados e watch() para executar efeitos colaterais em resposta a mudanças.

04 / Diretivas

Diretivas essenciais do Vue

Diretivas são atributos especiais que começam com v- e adicionam comportamento aos elementos HTML.

DiretivaFunçãoExemplo
v-ifRenderiza condicionalmente.v-if="logado"
v-elseAlternativa para uma condição.v-else
v-showAlterna a exibição via CSS.v-show="visivel"
v-forPercorre listas.v-for="item in itens"
v-bindVincula atributos.:href="url"
v-onEscuta eventos.@click="salvar"
v-modelVincula formulários.v-model="nome"
v-htmlInsere HTML.v-html="conteudo"

Condições com v-if

<script setup>
import { ref } from 'vue';
const logado = ref(false);
</script>

<template>
    <p v-if="logado">Você está conectado.</p>
    <p v-else>Faça login para continuar.</p>
</template>

Listas com v-for

<script setup>
const linguagens = ['HTML', 'CSS', 'JavaScript', 'Vue.js'];
</script>

<template>
    <ul>
        <li v-for="linguagem in linguagens" :key="linguagem">
            {{ "{{ linguagem }}" }}
        </li>
    </ul>
</template>

Use uma chave estável em :key para que o Vue identifique corretamente os elementos da lista quando ela mudar.

Eventos com @click

<script setup>
import { ref } from 'vue';
const mensagem = ref('Aguardando clique');

function mostrarMensagem() {
    mensagem.value = 'Botão clicado!';
}
</script>

<template>
    <button @click="mostrarMensagem">Clique aqui</button>
    <p>{{ "{{ mensagem }}" }}</p>
</template>

Formulários com v-model

<script setup>
import { ref } from 'vue';
const email = ref('');
</script>

<template>
    <label for="email">E-mail</label>
    <input id="email" v-model="email" type="email">
    <p>Você digitou: {{ "{{ email }}" }}</p>
</template>

Modificadores úteis

  • @submit.prevent: impede o comportamento padrão do formulário.
  • @keyup.enter: reage quando a tecla Enter é pressionada.
  • v-model.trim: remove espaços das extremidades de uma string.
  • v-model.number: tenta converter o valor para número.
  • v-model.lazy: atualiza a vinculação no evento de alteração, em vez de a cada entrada.

Segurança: evite usar v-html com conteúdo fornecido por usuários. HTML não confiável pode introduzir vulnerabilidades de XSS.

05 / Componentes

Componentes e reutilização

Componentes são blocos independentes de interface. Um botão, menu, cartão de produto ou formulário pode ser criado como componente e reutilizado em diferentes partes da aplicação.

Um componente .vue

Os arquivos Single-File Component usam a extensão .vue e podem reunir lógica, template e estilo.

<!-- Saudacao.vue -->
<script setup>
defineProps({
    nome: {
        type: String,
        required: true
    }
});
</script>

<template>
    <h2>Olá, {{ "{{ nome }}" }}!</h2>
</template>

<style scoped>
h2 {
    color: #42b883;
}
</style>

Usando o componente

<script setup>
import Saudacao from './components/Saudacao.vue';
</script>

<template>
    <Saudacao nome="Davi" />
</template>

Props e emits

  • Props: permitem que o componente pai envie dados para o filho.
  • Emits: permitem que o filho emita eventos que o pai pode ouvir.
<!-- BotaoAcao.vue -->
<script setup>
defineProps({
    texto: {
        type: String,
        default: 'Clique'
    }
});

const emit = defineEmits(['acionar']);
</script>

<template>
    <button @click="emit('acionar')">
        {{ "{{ texto }}" }}
    </button>
</template>
<!-- No componente pai -->
<BotaoAcao texto="Salvar" @acionar="salvarDados" />

Slots

Slots permitem que o componente pai forneça conteúdo para ser exibido dentro do componente filho.

<!-- Cartao.vue -->
<template>
    <article class="cartao">
        <slot>Conteúdo padrão</slot>
    </article>
</template>

<!-- Utilização -->
<Cartao>
    <h3>Meu produto</h3>
    <p>Descrição do produto.</p>
</Cartao>

Composition API e Options API

Composition API

Organiza a lógica usando recursos como ref, computed e funções reutilizáveis.

const contador = ref(0);

Options API

Organiza as opções do componente em propriedades como data, methods e computed.

export default {
  data() {
    return { contador: 0 };
  },
  methods: {
    somar() {
      this.contador++;
    }
  }
};

As duas abordagens são válidas. A Composition API com <script setup> é bastante comum em projetos Vue 3 modernos.

06 / Ciclo de vida

Lifecycle Hooks

O ciclo de vida representa as etapas pelas quais um componente passa, desde sua criação até sua remoção.

HookQuando usar
onMounted()Depois que o componente foi montado no DOM.
onUpdated()Depois que o componente atualizou o DOM.
onUnmounted()Depois que o componente foi desmontado.
onBeforeMount()Antes da montagem do componente.
onBeforeUnmount()Antes da remoção do componente.
 
<script setup>
import { onMounted, onUnmounted } from 'vue';

onMounted(() => {
    console.log('Componente montado');
});

onUnmounted(() => {
    console.log('Componente removido');
});
</script>

Use onUnmounted() para limpar recursos criados pelo componente, como temporizadores ou listeners que não sejam gerenciados automaticamente.

07 / Integrações

Consumindo APIs com Vue.js

Uma API permite que a aplicação consulte ou envie informações para outro sistema. JavaScript oferece fetch() para fazer requisições HTTP.

Consultando dados

<script setup>
import { ref, onMounted } from 'vue';

const usuarios = ref([]);
const carregando = ref(true);
const erro = ref('');

onMounted(async () => {
    try {
        const resposta = await fetch(
            'https://jsonplaceholder.typicode.com/users'
        );

        if (!resposta.ok) {
            throw new Error('Falha ao consultar a API');
        }

        usuarios.value = await resposta.json();
    } catch (e) {
        erro.value = e.message || 'Ocorreu um erro';
    } finally {
        carregando.value = false;
    }
});
</script>

<template>
    <p v-if="carregando">Carregando usuários...</p>
    <p v-else-if="erro">{{ "{{ erro }}" }}</p>

    <ul v-else>
        <li v-for="usuario in usuarios" :key="usuario.id">
            {{ "{{ usuario.name }}" }} — {{ "{{ usuario.email }}" }}
        </li>
    </ul>
</template>

Enviando dados com POST

async function criarUsuario(dados) {
    const resposta = await fetch('/api/usuarios', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json'
        },
        body: JSON.stringify(dados)
    });

    if (!resposta.ok) {
        throw new Error('Não foi possível criar o usuário');
    }

    return await resposta.json();
}

Atenção: o endereço /api/usuarios é um exemplo. Para funcionar, seu projeto precisa de um backend que disponibilize essa rota. Não coloque senhas ou chaves secretas privadas no código enviado ao navegador.

08 / Navegação

Vue Router

O Vue Router é a solução oficial de roteamento para aplicações Vue. Ele permite criar páginas e navegar entre elas sem recarregar a página inteira.

Instalação

npm install vue-router

Configurando as rotas

// src/router.js
import { createRouter, createWebHistory } from 'vue-router';

import Inicio from './views/Inicio.vue';
import Sobre from './views/Sobre.vue';

const routes = [
    { path: '/', component: Inicio },
    { path: '/sobre', component: Sobre }
];

const router = createRouter({
    history: createWebHistory(),
    routes
});

export default router;

Conectando ao aplicativo

// src/main.js
import { createApp } from 'vue';
import App from './App.vue';
import router from './router';

createApp(App)
    .use(router)
    .mount('#app');

Links e páginas

<template>
    <nav>
        <RouterLink to="/">Início</RouterLink>
        <RouterLink to="/sobre">Sobre</RouterLink>
    </nav>

    <RouterView />
</template>

RouterLink cria links de navegação e RouterView exibe o componente correspondente à rota atual.

09 / Estado global

Pinia

Pinia é a solução recomendada para gerenciamento de estado em aplicações Vue modernas. Ela permite compartilhar dados entre componentes sem precisar passar props por muitos níveis.

Instalação

npm install pinia

Registrando o Pinia

// src/main.js
import { createApp } from 'vue';
import { createPinia } from 'pinia';
import App from './App.vue';

const app = createApp(App);

app.use(createPinia());
app.mount('#app');

Criando uma store

// src/stores/contador.js
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';

export const useContadorStore = defineStore('contador', () => {
    const valor = ref(0);

    const dobro = computed(() => valor.value * 2);

    function incrementar() {
        valor.value++;
    }

    return { valor, dobro, incrementar };
});

Usando a store em um componente

<script setup>
import { useContadorStore } from './stores/contador';

const contador = useContadorStore();
</script>

<template>
    <p>Valor: {{ "{{ contador.valor }}" }}</p>
    <p>Dobro: {{ "{{ contador.dobro }}" }}</p>
    <button @click="contador.incrementar">Incrementar</button>
</template>

Use uma store quando o estado realmente precisar ser compartilhado. Para dados usados em apenas um componente, ref() pode ser suficiente.

10 / Estilização

CSS em componentes Vue

Em arquivos .vue, o CSS pode ficar na seção <style>. A opção scoped limita a aplicação dos estilos aos elementos daquele componente.

<template>
    <button class="botao">Meu botão</button>
</template>

<style scoped>
.botao {
    background: #42b883;
    color: #08130e;
    border: 0;
    padding: 12px 18px;
    border-radius: 8px;
    cursor: pointer;
}

.botao:hover {
    background: #35d49a;
}
</style>

Classes dinâmicas

<script setup>
import { ref } from 'vue';

const ativo = ref(false);
</script>

<template>
    <button
        :class="{ ativo: ativo }"
        @click="ativo = !ativo"
    >
        Alternar estado
    </button>
</template>

<style scoped>
.ativo {
    background: #42b883;
    color: #07130e;
}
</style>

12 / Qualidade

Testes e depuração

Testes ajudam a verificar se a aplicação funciona como esperado. Em projetos Vue, as ferramentas escolhidas dependem do tamanho e das necessidades do projeto.

Vitest

Executa testes unitários e de componentes em projetos modernos baseados em Vite.

Vue Devtools

Ajuda a inspecionar componentes, estado e eventos durante o desenvolvimento.

Playwright

Permite testar fluxos completos de uma aplicação em um navegador real.

Exemplo de teste com Vitest

import { describe, it, expect } from 'vitest';

function somar(a, b) {
    return a + b;
}

describe('função somar', () => {
    it('soma dois números', () => {
        expect(somar(2, 3)).toBe(5);
    });
});
13 / Tipagem

Vue.js com TypeScript

TypeScript adiciona tipos ao JavaScript. Ele pode ajudar a identificar erros antes da execução e melhorar a experiência de desenvolvimento em projetos maiores.

<script setup lang="ts">
import { ref, computed } from 'vue';

interface Produto {
    id: number;
    nome: string;
    preco: number;
}

const produtos = ref<Produto[]>([
    { id: 1, nome: 'Teclado', preco: 120 },
    { id: 2, nome: 'Mouse', preco: 80 }
]);

const total = computed(() =>
    produtos.value.reduce((soma, produto) => soma + produto.preco, 0)
);
</script>

<template>
    <p>Total: R$ {{ "{{ total.toFixed(2) }}" }}</p>
</template>
14 / Publicação

Preparando para produção

Quando o projeto estiver pronto, crie uma versão otimizada para publicar em um serviço de hospedagem estática ou em uma infraestrutura compatível com a aplicação.

# Gerar a versão de produção
npm run build

# Testar localmente a versão gerada
npm run preview

Em um projeto Vite padrão, os arquivos gerados ficam na pasta dist/.

Onde hospedar?

  • Serviços de hospedagem estática que aceitam projetos Vite.
  • Plataformas de deploy conectadas ao GitHub.
  • Servidores próprios configurados para servir os arquivos da aplicação.

Se você usar Vue Router com histórico HTML5, configure o servidor para encaminhar rotas desconhecidas ao arquivo index.html. Sem isso, acessar diretamente uma rota interna pode resultar em erro 404.

15 / Profissionalização

Boas práticas de desenvolvimento

  • Crie componentes pequenos e com responsabilidades claras.
  • Use nomes de variáveis e funções que expliquem sua finalidade.
  • Prefira computed() para valores derivados.
  • Use :key estável ao renderizar listas.
  • Valide os dados recebidos de formulários.
  • Trate erros e estados de carregamento nas requisições.
  • Evite duplicar lógica em vários componentes.
  • Não coloque credenciais privadas no código do navegador.
  • Escreva testes para as partes importantes da aplicação.
  • Leia a documentação oficial quando encontrar comportamentos desconhecidos.

Erros comuns

ProblemaComo resolver
Esquecer .value no JavaScriptAo usar um ref no script, acesse ou altere seu valor por .value.
Lista sem :keyUse um identificador estável para cada elemento.
Usar variável comum esperando reatividadeUse ref() ou reactive() quando necessário.
Componente não encontradoConfira o caminho e a importação do componente.
API não respondeVerifique URL, conexão, CORS e resposta HTTP.
Rota dá 404 após atualizarConfira a configuração de fallback do servidor.
